# Svelte Vite App Example

This example demonstrates the `rules_monorepo_frontend` pnpm/Svelte/Vite
macros, including checks, Playwright smoke testing, and static nginx OCI image
packaging.

Key targets:

- `//examples/svelte_vite_app:bundle`
- `//examples/svelte_vite_app:checks`
- `//examples/svelte_vite_app:playwright_test`
- `//examples/svelte_vite_app:frontend_image`
